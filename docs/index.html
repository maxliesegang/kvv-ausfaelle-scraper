Verification statuses

Trips carry an optional advisory verification field recording what external realtime sources later observed. It never changes the record's primary meaning — that KVV announced the trip as cancelled — and is absent for trips outside every provider's rolling lookback window. Fallback routing data is provided by Transitous and its listed sources.

cancelled — Cancelled
The realtime source confirms the announced segment did not run — either it flagged the trip or its stops as cancelled, or it tracked the vehicle either side of a segment it never observed it on.
partial — Partly cancelled
Only part of the announced segment was cancelled, or only part of it was observed. The notice and reality agree in part.
ran — Ran
The source observed the vehicle across the whole announced segment with no cancellation flag. The trip KVV announced as cancelled appears to have run.
no-data — No data
The source knows the journey but holds neither cancellation flags nor realtime for the announced segment, so it says nothing either way. Absence of evidence, not evidence of absence.
unresolved — Unresolved
No journey matching the trip could be identified in the source, so it was never in a position to answer.

Cancellation causes

Ordered cause taxonomy published in index.json for downstream consumers.

strike — Streik
Arbeitskampf, Streik oder Warnstreik.
weather — Witterung
Witterungseinflüsse wie Unwetter, Sturm, Eis oder Hochwasser.
emergency — Einsatz von Rettungskräften
Ein gemeldeter Einsatz von Feuerwehr oder anderen Rettungskräften.
vehicle — Fahrzeugstörung
Eine benannte Störung oder ein Schaden am eingesetzten Fahrzeug.
infrastructure — Infrastrukturstörung
Eine benannte Störung an Stellwerk, Signal, Oberleitung, Weiche oder Gleis.
technical — Technischer Defekt
Eine technische Störung, ohne dass Fahrzeug oder Infrastruktur benannt sind.
personnel — Personalmangel
Ein ausdrücklich genannter Personalengpass oder krankheitsbedingter Ausfall.
operational — Betriebsbedingt
Ein betrieblicher Grund ohne zuverlässige Benennung einer konkreteren Ursache.
disruption — Betriebsstörung
Eine gemeldete Betriebsstörung ohne näher benannte Ursache.
construction — Bauarbeiten
Bau-, Instandhaltungs- oder Sperrmaßnahmen an der Strecke.
unknown — Unbekannt
Aus dem Artikel konnte keine Ursache zuverlässig bestimmt werden.
